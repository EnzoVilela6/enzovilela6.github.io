Le projet

Mettre en place un serveur Linux hébergeant une plateforme Nextcloud, pour offrir aux utilisateurs un espace de stockage et de partage de fichiers accessible depuis un navigateur web.

Les étapes

  • Création d’une machine virtuelle et installation de Debian Server
  • Vérification de la configuration réseau avec ip a : adresse IP attribuée, machine connectée et accessible

  • Contrôle du service avec systemctl status apache2 : actif et prêt à répondre
